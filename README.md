# AI520 · AI 结构化知识库

**在线阅读：https://1nny2.github.io/AI520/**

收集 AI 短文，保留原文与收录日期，提取核心信息，并按面试、工作实践和架构设计等场景分类。

## 从哪里开始

打开在线首页，可搜索关键词、筛选场景，并进入文章阅读页。

**首页 → 场景 / 搜索 → 阅读页 → 原文、总结长图或文字备份。**

## 文件关系

- `index.html`：网站首页。
- `打开知识库.html`：兼容本地知识库的中文入口。
- `阅读版/`：排版阅读页及公共样式。
- `阅读图片/`：每篇总结的完整长图。
- `文章/`：原文与总结的 Markdown 文字备份。
- `场景分类索引.md`：备用文字索引。

同一篇文章在三个目录中沿用同一编号与文件名主体，分别使用 `.html`、`.png` 和 `.md` 扩展名。

## 阅读说明

收录日期与原文发布日期分别标注；原文日期未知时如实说明。作者观点与整理者补充在笔记中区分。

网站采用静态 HTML，无需注册或登录。下载整个仓库后，也可以直接打开 `index.html` 离线阅读。
